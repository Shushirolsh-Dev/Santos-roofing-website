# Santos Roofing — Website Concept

An independent, speculative website concept for a roofing business in Austin, Texas. This is a portfolio preview only and is not an official website or an authorised representation of the business.

## Preview

A responsive, single-page landing page built with HTML, CSS and vanilla JavaScript. No build step or dependencies are required.

## Run locally

Open `index.html` in a browser, or serve the repository with any static file server.

## Before any commercial launch

- Obtain the business owner's permission and confirm all business details.
- Replace the demo enquiry form with an authorised destination email or CRM.
- Confirm services, service area, claims, contact details and imagery with the business.
- Agree in writing on payment, ownership/licensing, hosting and handover terms.
